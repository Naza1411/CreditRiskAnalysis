# Week 4 — Deliver an Excel Credit Portfolio Dashboard

## Assignment to send

Management wants a one-page view of Cedar MFB's repayment portfolio. Turn the Week 3 tracker into an auditable dashboard and recommend two actions.

### Learn — maximum 90 minutes

Review unit versus value delinquency, outstanding balance, amount due, amount collected, collection rate and portfolio at risk. Learn why a numerator, denominator, date and exclusion rule are part of every metric definition.

### Build — 7 hours

1. Create a clean dashboard with a reporting-date selector.
2. Show loans disbursed, active accounts, outstanding principal, amount due, amount collected and collection rate.
3. Show unit and value delinquency by DPD bucket.
4. Break exposure down by product and origination month.
5. Add filters for product, channel and customer type.
6. Create a metric-definition tab and a reconciliation tab.
7. Write two actions supported by the results.

### Submit

- Final `project_01_loan_repayment_dashboard.xlsx`
- One-page management memo
- README with refresh instructions
- A 5-minute recorded or live walkthrough

### Acceptance criteria

- Dashboard totals reconcile to the source tabs.
- Filters do not break denominators.
- Charts have clear titles, units and reporting dates.
- Recommendations identify an owner and monitoring metric.

### Stretch task

Use Power Query to import and refresh the source tables.
