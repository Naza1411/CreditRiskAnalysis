### Week 3 - Loan Repayment Tracker
#### Overview
This project develops an Excel-based loan repayment tracker for Cedar Microfinance Bank (Cedar MFB).
The objective is to build a synthetic repayment dataset and use it to monitor loan performance, calculate arrears and Days Past Due (DPD), classify loans into delinquency buckets, identify data-quality exceptions, and demonstrate how payment-allocation methodology can affect loan-level delinquency reporting.

The tracker contains: 20 synthetic loans, 60 instalments, and Six repayment behaviours: On-time, Late, Partial, Missed, Prepaid, and Cured
The model is designed around a user-selected reporting date so that historical portfolio performance can be assessed without incorrectly including future payments.

Objectives: The project addresses the following credit-risk monitoring requirements:
1.	Expand the synthetic dataset to at least 20 loans and 60 instalments.
2.	Include different repayment behaviours.
3.	Define and document a payment-allocation rule.
4.	Calculate cumulative amount due, cumulative amount paid, arrears, oldest unpaid due date and DPD.
5.	Assign loans to delinquency buckets.
6.	Produce an exception report for data-quality problems.
7.	Compare the effect of different payment-allocation methods as a stretch analysis.
